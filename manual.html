STAGE 1

If the screen is 1, press 1.

STAGE 2

If the screen is 1, press 2.

STAGE 3

If the screen is 1, press 3.

If the screen is 2, press 4.

If the screen is 4, press 2.

STAGE 4

If the screen is 1, press 4.

If the screen is 2, press 3.

If the screen is 3, press 2.

If the screen is 4, press 1.

STAGE 5

If the screen is 1, press 2.

If the screen is 2, press 3.

If the screen is 3, press 4.

If the screen is 4, press 1.

IMPORTANT: In Stage 1, the button numbers are visible. After Stage 1, the numbers disappear but the buttons DO NOT MOVE. Remember where buttons 1–4 were. A new Memory module randomizes the four button positions again.

Easy uses Stages 1–3. Medium uses Stages 1–4. Hard / Very Hard use Stages 1–5.
